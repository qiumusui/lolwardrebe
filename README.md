# 👗 Lolita 裙柜记录 (Lolita Wardrobe PWA)

一个粉嫩可爱的手机端 Lolita 裙子记录 Web App（PWA）。纯前端、数据存本地、可离线、可"添加到主屏幕"当原生 App 用。

## 功能
- **月度预算与累计额度**：设置每月购买额度，记录下定自动扣减；上月未用完额度可选择性累计到下月（递归结转正数、不结转超支）。
- **裙柜管理**：记录裙子 / 配饰 / 鞋子 / 其他；裙子细分 JSK / OP / 背带 / 内搭等款式；支持类型 + 款式 + 价格区间三级组合筛选，显示各区间数量、总价与衣橱总价值。
- **尾款日历与提醒**：月历标记有尾款的日期，按倒计时提醒；状态改为"已到货 / 已拥有"后，尾款（总价 − 已付）自动计入**尾款日期所在月份**的预算。
- **图片上传**：裙子可上传照片（自动压缩到最大宽 720px 的 JPEG），数据存浏览器本地。

## 技术栈
- 纯 HTML / CSS / JavaScript（无框架、无构建步骤）
- 数据持久化：`localStorage`
- PWA：`manifest.json` + `sw.js`（网络优先缓存，刷新即最新）

## 本地运行
PWA 的 service worker 需要 http 环境，请用静态服务器打开：

```bash
python -m http.server 8123
# 或
npx serve .
```

然后浏览器访问 http://localhost:8123/

手机预览：把 `localhost` 换成电脑局域网 IP（如 `http://192.168.1.x:8123`），手机与电脑同一 WiFi，浏览器菜单"添加到主屏幕"。

## 目录
| 文件 | 作用 |
|------|------|
| `index.html` | 主界面结构 |
| `css/style.css` | 样式（Lolita 粉嫩风、响应式） |
| `js/app.js` | 全部逻辑（数据层 / 预算 / 裙柜 / 日历 / 统计 / 弹窗 / 图片 / 尾款扣款） |
| `manifest.json` | PWA 安装配置 |
| `sw.js` | 离线缓存 |
| `icon.svg` | 图标 |

## 数据备份
裙子数据存于浏览器 `localStorage`（**不在源码中**）。建议定期在 App 内"导出 JSON"备份，换设备时"导入"恢复。
